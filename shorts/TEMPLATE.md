## 原文

ここに原文を変更せずに置くか、利用許可のある元資料への参照を記録します。個人情報を公開する必要はありません。創作したセリフや数値を後から原文へ混ぜません。

## 台本と画面

開始・終了は秒で設計し、実装では同じfpsからフレームに変換します。「登場開始→完全表示→退場」の順序を守ります。読む時間は完全表示後に確保します。

| 場面 | 開始〜終了 | 画面に出す正確な文章・話者 | 登場順と完全表示時刻 | 読む時間／間／思考時間 | 動き・画面状態 | 音声・音 | 原文からの変更 |
|---|---|---|---|---|---|---|---|
| 冒頭 | | | | | | | |
| 展開 | | | | | | | |
| オチ／答え | | | | | | | |

会話型は各発言に一意のID、話者、表示開始、入力中の時間、読める保持時間を設定します。ゲーム型は選択前・選択中・結果を区別します。英語クイズ型は問題・全選択肢の完全表示時刻とカウントダウン開始時刻を分けます。
