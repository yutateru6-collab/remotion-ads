# 制作例：手伝う気ありますアピール旦那

状態：**台本・演出設計のみ。新しい動画の実装、書き出し、視聴検品は未実施。**

同じ原稿でも、何を面白さの中心にするかでモードを変える例です。時間は初稿の目安で、実際に読んで調整します。３案を１本に全部混ぜるものではありません。

## 原文（ユーザー提供）

「手伝う気ありますアピール旦那」（38歳・家庭内アルバイト感覚の男）

### 特徴

「手伝おうか？」とドヤ顔で言えば「俺は協力的な夫」というポジションを確保できると思い込んでいる、育児も家事も「お手伝い感覚」のエセイクメン。実際は、「やれと言われたらやるけど、自分から動く気はゼロ」なので、妻が返事をしなかった場合は「あ、いいんだ？」とそのままスマホをいじる。自分の中では「ちゃんと申し出た」ことになっているので、「俺はやる気あったのに、妻が頼まなかっただけ」という言い訳が完成。

### 行動例

- 妻が洗濯物を畳んでいる横で、「手伝おうか？」と聞くが、実際は「手伝わない選択肢」を確保したいだけ。
- 子どもが泣いていても「手伝おうか？」と一旦聞いてから行動 → 「もういいから早くやれよ！」とキレられる。
- 「手伝おうか？」と言った後に妻が「お願い」と言うと、「えー、俺がやるの？（ﾁｯ）」と謎の不満顔。
- 「手伝おうか？」と聞いておきながら、「じゃあお願い」と言われると「やり方わかんないんだけど？」と無駄に聞きまくり、結局妻がやった方が早い状況を作る。

元原稿の太字などの装飾は上では省き、文章を保持しています。以下の台本は短縮・再構成した別データです。

## A. 最初に作る案：文字ツッコミ型

主モード：`text-tsukkomi`。原稿の「申し出たことを免責にする」という矛盾を中心にする。３つの別行動例は続編候補に分ける。無音で成立させる。

| 時間 | 表示する文言 | 出し方 |
|---|---|---|
| 0〜4秒 | 「手伝おうか？」の正体 | 冒頭から本文を見せる。小さなシリーズ名「架空悪口図鑑」と「架空の人物」を添える。長い人物紹介は先に出さない。 |
| 4〜9秒 | 妻は洗濯物を畳んでいる。／夫「手伝おうか？」 | 状況と発言を別レイヤーで早い段階に出し、残りは読む時間にする。 |
| 9〜14秒 | 妻、返事なし。／「あ、いいんだ？」 | まず妻の状態。読める間を置き、夫の発言だけを追加する。 |
| 14〜20秒 | そのままスマホ。／本人の中では、申し出完了。 | 上段に行動、下段に本人の認識。下段の「完了」だけを強調する。 |
| 20〜27秒 | 「俺はやる気あったのに」／「頼まれなかっただけ」 | 前半を読んでから後半。文字をずっと揺らさない。 |
| 27〜34秒 | 言い訳だけ、／準備がいい。 | 前置きを表示してから短い間。最後の一言を出し、読み終わるまで保持する。 |

想定尺：34秒。動画の実出力値ではない。

**編集点：** 「言い訳だけ、準備がいい。」は追加した創作のツッコミ。「申し出完了」も演出上の言い換え。年齢・肩書きは冒頭の可読性のため省略。原稿にない質問回数などの数値は追加しない。

**固定する見た目：** 発言＝大きい黒文字、状況＝落ち着いた本文、ツッコミ＝アクセント。色だけで区別せず位置・大きさも使う。文字・ラベル・強調は編集可能な別レイヤーにする。

**最重要の検品：** ９〜14秒と20〜27秒の２段階表示が読めるか。27秒以降のオチを早く出しすぎないか。動画の終わりを新たな長文説教に変えていないか。

## B. 会話型にする場合

主モード：`chat-story`。原稿の「お願いと言われると嫌がる」という行動例だけを使う。架空チャットへの翻案であり、本物のメッセージではない。

| 順 | 話者／表示 | 演出 |
|---|---|---|
| 1 | 夫「手伝おうか？」 | 架空チャットUIの右側に表示。 |
| 2 | 妻「お願い」 | 前の発言を読んだ後、左側に表示。 |
| 3 | 夫が入力中…… | 返答への期待を作る。必要以上に長くしない。 |
| 4 | 夫「えー、俺がやるの？」 | 入力中表示と置き換える。 |
| 5 | 妻「今、自分で聞いたよね？」 | 追加の創作セリフとして扱う。最後の吹き出しを読める時間保持する。 |

**編集点：** 元原稿の対面の発言をチャットに変更。妻の最後のセリフは新規。「やり方わかんないんだけど？」は別エピソードにし、１本に全部足さない。

**検品：** 送信者と左右の対応、最後の吹き出しの見切れ、入力中表示と返信の重複、無音での理解を確認する。

## C. ゲーム・診断型にする場合

主モード：`game-ui`。このフォーク独自の架空ゲーム画面を作る。既存の完成ゲームテンプレートを呼び出すだけではない。

| 状態 | 表示 | 演出 |
|---|---|---|
| 状況 | 妻が洗濯物を畳んでいる。 | 状況を読める時間保持する。 |
| 選択前 | 洗濯物を畳む／「手伝おうか？」と聞く | ２つの選択肢を表示。 |
| 選択中 | 「手伝おうか？」と聞く | カーソル移動→選択状態を保持。 |
| 結果 | 「協力した感」を獲得！ | 架空ゲームの結果として出す。実在の心理評価にはしない。 |
| オチ | 家事は、進んでいない。 | 獲得表示とのズレを見せ、読む時間を残す。 |

**編集点：** 選択肢と獲得表示は原稿をもとにした創作。点数・回数・割合は不要。ボタンは動画内の演出で、視聴者が操作できるUIではない。
