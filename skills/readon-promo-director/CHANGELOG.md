# READON Promo 改善記録

## V1
- 実READON画面をPlaywrightで取得する基盤を作成。
- 弱点: 画面＋字幕に近く、映像言語と音が弱かった。

## V2
- 10ショット前後へ増加。
- 2.5D風、モーショングラフィックス、AIナレーション、BGM/SFXを追加。
- 良かった点: Pain→Transformation構造、実画面の信頼性。
- 問題:
  - Linuxレンダーで日本語フォントがCJK fallbackに落ちうる構成。
  - 26〜37px程度の補助文字がスマホで小さい。
  - 30秒は説明感が出やすい。
  - 英語の小見出しが多く、日本語視聴者の視線を分散。
  - CTAでURLが視覚的に強すぎた。

## V3 方針
- FontsourceでZen Kaku Gothic New / BIZ UDPGothicを自己ホスト。
- 22秒へ圧縮。
- 主見出し82〜106px、補助50px前後。
- 冒頭2.5秒以内にREADON名を表示。
- TikTok右端・最下部から重要情報を退避。
- CTAは「READONを開く」を主役にする。
- ナレーションを短く再生成し、BGMを弱める。

次回の改善時はV3完成MP4の弱点をこのファイルに追記する。
