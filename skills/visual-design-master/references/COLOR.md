# Color

## Start neutral

Build the layout in grayscale first. Add color after hierarchy works.

## Default palette discipline

Unless the concept calls for something else:
- background / surface neutral;
- ink / primary text;
- muted secondary neutral;
- one accent.

Semantic colors are allowed for status when meaning requires them.

## Accent

The accent should identify one of:
- the active action;
- the key word;
- the state change;
- the payoff.

If the accent appears everywhere, it stops being an accent.

## Contrast

Use luminance contrast before decorative effects. Do not rely on glow or shadow to rescue low-contrast type.

## Series consistency

For a repeated series, store the palette as tokens and do not slightly change the same color every episode.
