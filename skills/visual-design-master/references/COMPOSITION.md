# Composition & Visual Hierarchy

## First question

At this frame, **where should the eye go first?**

If the answer is unclear, the frame is not ready.

## Three tiers

Classify visible information:
- **Primary** — one dominant object/message/action.
- **Secondary** — supports the primary.
- **Tertiary** — metadata or atmosphere; easy to ignore.

Primary and secondary must not have equal visual weight.

## Build hierarchy with this order

Prefer:
1. size;
2. position;
3. spacing;
4. weight;
5. contrast;
6. color;
7. decoration.

Do not start with glow, border or shadow.

## Negative space

Empty space is an active separator.

Use:
- tight spacing = same idea;
- medium spacing = same group;
- large spacing = new idea.

If the layout only works after adding boxes around everything, grouping is weak.

## Eye path

For each important beat, describe:
1. first fixation;
2. second destination;
3. exit direction into the next beat.

Motion should support this path.

## Anti-card rule

Cards are allowed only when the content has a real repeated-unit structure.
Do not wrap every sentence, metric, or label in a card.

## Density

Prefer 1–3 meaningful objects over many small objects.
When the frame feels empty, first ask whether the main object can become more specific or larger before adding filler.
