# Universal Visual Design

This is the quality layer that runs **before** content-specific formats such as text comedy, chat stories, quizzes, app demos, ads, or explainers.

The goal is not “make it prettier.” The goal is to make every frame feel intentionally designed.

## Core rule

**Content format answers WHAT the piece is. This skill answers WHY it looks professionally designed.**

Never begin with cards, gradients, or animation presets. Begin with intent, hierarchy, and composition.

## 1. Art direction — choose one visual thesis

Write one sentence describing the visual world before implementation.

Examples:
- Japanese editorial minimalism: off-white paper, black ink, one vermilion accent, asymmetric type.
- Swiss modernism: strict grid, oversized grotesk type, neutral palette, strong negative space.
- Playful toy packaging: bold flat colors, chunky type, sticker-like shapes, controlled bounce.
- Quiet luxury: warm neutral surface, serif/sans contrast, slow movement, generous space.

Rules:
- One dominant aesthetic per piece.
- Avoid generic “AI style”: cyan-purple gradients, random glow, glass cards, excessive rounded panels.
- Decoration must support the thesis.

## 2. Visual hierarchy — one winner per beat

For every beat, identify:
- PRIMARY: what the eye must see first.
- SECONDARY: what supports it.
- TERTIARY: what may be ignored until later.

Rules:
- One primary focal object per beat.
- If two elements compete, pick a winner.
- Demote with scale, weight, position, opacity, and spacing before adding more color.
- Do not fill empty space just because it is empty.

## 3. Composition — structure before styling

Design each frame in grayscale first.

Check:
- focal point
- negative space
- alignment
- edge tension
- grouping
- balance
- reading order

Rules:
- Avoid “center everything.”
- Avoid disconnected card grids unless the content is genuinely a grid.
- Use a grid, but break it intentionally when emphasis requires it.
- Keep meaningful relationships spatially close.
- Prefer fewer, larger objects over many small objects.

## 4. Typography — type is layout

Use typography as a compositional system, not captions pasted on top.

Rules:
- Limit to 1–2 type families.
- Use a deliberate size scale; no arbitrary jumps.
- One emphasized phrase is stronger than five bold words.
- Japanese line breaks follow meaning, not character count.
- Avoid orphaned particles and punctuation.
- Mix Japanese and Latin with deliberate baseline, weight, and spacing.
- Prefer short lines for impact; longer copy needs a clear reading rhythm.
- Do not animate every character unless the concept requires it.

## 5. Color — restraint creates identity

Rules:
- Start neutral-first.
- Use one main accent by default.
- Semantic colors only when they carry meaning.
- Contrast must survive grayscale.
- Background color is part of composition, not decoration.
- Never add gradients merely because the frame feels empty.

## 6. Motion — motion must explain something

Every movement must do at least one:
- direct attention
- reveal causality
- show state change
- establish scale
- transition spatially
- create emotional timing

Use:
- hold → move → hold
- primary / secondary / ambient motion layers
- anticipation and settle for impact beats
- stable end holds

Avoid:
- constant motion
- meaningless zooms
- every element entering independently
- identical spring animation on every object
- movement that hides the object while it should be read

## 7. Detail and polish

Only after hierarchy works:
- optical alignment
- consistent radii if used
- shadow only when it explains depth
- texture only when it belongs to the art direction
- icon stroke consistency
- clean crops
- intentional edge spacing

A polished bad composition is still bad.

## 8. Visual QA — inspect actual output

Do not approve from source code alone.

Before delivery:
1. Render opening, middle, payoff, and ending frames.
2. Create a contact sheet.
3. Watch the full piece at normal speed without pausing.
4. Check first-read focal point for every beat.
5. Check text is readable before it exits.
6. Check there are no dead frames, accidental collisions, weak crops, or generic filler.
7. Compare against the chosen visual thesis.
8. Revise if any frame looks like a template rather than a designed composition.

## Universal rejection gate

Reject and revise if ANY is true:
- The first frame has no obvious focal point.
- More than one element shouts at the same time.
- The piece relies on cards for structure without a content reason.
- Typography is only “big bold centered.”
- Color is doing work that layout should do.
- Motion is decorative rather than causal.
- Every beat has the same rhythm.
- The final hold feels unfinished.
- The design could be swapped onto an unrelated topic unchanged.

## Relationship to content-specific modes

Run this first. Then apply the relevant format:
- text comedy
- chat story
- game/diagnostic UI
- learning/quiz
- app/product demo
- ad/explainer

If format rules conflict with visual quality, preserve clarity, hierarchy, and readability first.
