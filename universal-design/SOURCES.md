# Source influences and adaptation

This skill is an original synthesis for this repository.

Concepts were informed by public MIT-licensed skills and design systems, especially:
- wgawan/ui-system-discipline — hierarchy, structure-first layout, spacing discipline.
- LottieFiles/motion-design-skill — motion intent and choreography.
- Liamrjohnston/remotion-motion-graphics-skill — cinematic camera, reference inspection, output QA.
- Maartenlouis/remotion-ads — Remotion short-form typography and pacing patterns.

Do not treat any one source as a complete solution. This layer intentionally separates universal visual quality from content-specific video formats.
